Objective:
Create a professional web-based dashboard application using Java (only) as the core programming language. The system should visually demonstrate searching and sorting algorithms with step-by-step (iteration-wise) visualization, user input, file support, and performance insights.

🏗️ Functional Requirements
Main Dashboard Page

Show two primary sections or cards:

🔍 Searching

🔢 Sorting

When a user selects one, navigate inside that category.

Searching Section

Algorithms available:

Linear Search

Binary Search

Ask the user to:

Enter the array elements (manually or via CSV file)

Enter the target element

Show each iteration visually (highlighting index comparisons).

Sorting Section

Algorithms available:

Selection Sort

Insertion Sort

Merge Sort

Bubble Sort

Quick Sort

Ask the user to:

Enter or upload array input (CSV)

Show each iteration:

Array status after every comparison or swap

Highlight which elements are being compared or moved

Visualization

Each iteration must be displayed clearly (like step-by-step animation or state display)

Option to pause, resume, or restart

Clean, modern, and responsive UI (use any front-end visualization tools, e.g. HTML, CSS, JS, React, or JavaFX)

Output / Reports

Allow the user to export a PDF or CSV file containing:

Every iteration (array state and action taken)

Total time taken for completion

Space complexity and time complexity (best, average, worst)

Add a recommendation message:

“For the given input size, Quick Sort would perform better than Bubble Sort”
(based on theoretical complexity)

Complexity Display

After each run, show:

Time complexity: O(n²), O(n log n), etc.

Space complexity: O(1), O(n), etc.

A short description of when it performs best or worst.

🧩 Technical Constraints
Core logic must be written in Java.

You can use any front-end framework for visualization (e.g. React, Vue, Angular, or plain JS).

No additional backend services — everything should run on Java (e.g., using Servlets, JavaFX, or embedded web server).

Allow input through:

Manual text input

CSV file upload

Support PDF generation (showing all iterations and analysis).

🎨 UI / UX Guidelines
Professional and superior dashboard design (modern card layout, soft shadows, gradients).

Dashboard layout:

Header with title: “Algorithm Visualization Dashboard”

Sidebar (optional): “Home”, “Sorting”, “Searching”, “Reports”

Main content area: visualization panel + iteration table

Each iteration appears as:

Iteration 3: [1, 2, 4, 3, 5] → swapped elements at index 2 and 3
Add live progress indicators (e.g. iteration count, percentage done).

🕒 Performance & Recommendation Logic
Track:

Time taken for each iteration

Total execution time

After execution, automatically display:

“Quick Sort is more efficient (O(n log n)) than Bubble Sort (O(n²)) for arrays of this size.”

Optionally, show a bar graph comparing the complexity of available algorithms.

📄 Deliverables (expected outputs)
Fully working web dashboard (Java-driven)

CSV upload and parsing support

Real-time iteration visualization

PDF export showing:

Each iteration

Complexity

Total time and space used

Clean, animated, and responsive front-end
